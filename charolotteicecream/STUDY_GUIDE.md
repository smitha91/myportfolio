# Charlotte's Ice Cream Study Guide

## Purpose
A fun, interactive web project simulating a luxury ice cream shop experience.

## Key Features
- Interactive UI with JavaScript
- Dynamic flavor selection
- Modal popups for details
- Responsive design

## Structure
- `index.html`: Main page
- `script.js`: Handles interactivity (flavor selection, modals)
- `style.css`: Custom styles
- `images/`: Ice cream images

## What It Demonstrates
- DOM manipulation
- Event handling
- Responsive, interactive UI

## Example Flow
1. User selects a flavor
2. Modal shows details and image
3. User can browse and interact with the menu
