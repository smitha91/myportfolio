# Secure Login Feature Study Guide

## Purpose
A secure login/register system demonstrating authentication best practices.

## Key Features
- Registration and login forms
- Password hashing (bcrypt)
- Session or JWT-based authentication
- EJS templating for views

## Structure
- `views/`: EJS templates for login, register, etc.
- Backend logic (in main server or separate file)

## What It Demonstrates
- Secure authentication flows
- Password security
- Server-rendered forms

## Example Flow
1. User registers or logs in
2. Credentials are securely handled
3. User is authenticated and redirected to protected content
