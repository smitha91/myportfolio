# SkylinkMenu Study Guide

## Purpose
A digital menu experience for a luxury aviation-themed dining service.

## Key Features
- Interactive menu UI
- Responsive design
- Themed for aviation luxury

## Structure
- `index.html`: Menu page
- `script.js`: Handles menu interactivity
- `style.css`: Custom styles

## What It Demonstrates
- UI/UX for digital menus
- Responsive, interactive design

## Example Flow
1. User browses menu items
2. Interacts with menu for more details or selections
