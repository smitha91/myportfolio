# SkyList Task Management Study Guide

## Purpose
A task management app themed for aviation, demonstrating CRUD operations and state management in vanilla JS.

## Key Features
- Add, edit, delete, and complete tasks
- Persistent state (localStorage or in-memory)
- Responsive, aviation-themed UI

## Structure
- `index.html`: Main page
- `script.js`: Task logic and UI updates
- `style.css`: Custom styles

## What It Demonstrates
- CRUD logic in JavaScript
- State management
- Responsive design

## Example Flow
1. User adds a new task
2. Tasks can be marked complete, edited, or deleted
3. All changes update the UI in real time
